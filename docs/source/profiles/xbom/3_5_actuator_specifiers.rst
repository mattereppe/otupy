3.5 Actuator Specifiers
=======================

XBOM defines two optional actuator specifiers:

.. list-table:: XBOM actuator specifiers
   :header-rows: 1

   * - Name
     - Type
     - Meaning
   * - ``domain``
     - ``str``
     - Domain under the responsibility of the actuator.
   * - ``asset_id``
     - ``str``
     - Identifier of the selected actuator or managed asset.
