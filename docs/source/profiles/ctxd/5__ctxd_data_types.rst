5. CTXD Data Types
==================

CTXD context objects are maintained in :mod:`otupy.models.ctxd`. The model
contains the core :py:class:`~otupy.models.ctxd.Service`,
:py:class:`~otupy.models.ctxd.Link`, and
:py:class:`~otupy.models.ctxd.SId` types together with concrete service,
network, execution-environment, and peer types.

For field-level details, use the generated API reference for
:mod:`otupy.models.ctxd`; it is the source-of-truth view of the current Python
model and avoids duplicating the schema manually in two places.
