SLPF - Stateless Packet Filtering
=================================

SLPF is the OpenC2 Stateless Packet Filtering profile implemented by ``otupy``.
Its namespace identifier is ``slpf`` and the implementation points to the OASIS
SLPF 1.0 profile definition.
