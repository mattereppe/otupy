4. SLPF Data Types
==================

``Direction``
   Enumeration selecting ``both`` (1), ``ingress`` (2), or ``egress`` (3).

``DropProcess``
   Enumeration selecting ``none`` (1), ``reject`` (2), or ``false_ack`` (3)
   behavior when traffic is dropped.

``RuleID``
   Integer target registered as ``slpf:rule_number``.
